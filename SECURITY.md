# Security Policy

## Supported version

Security fixes are applied to the latest version of Auto Wipe.

## Reporting a vulnerability

Please report security vulnerabilities privately rather than opening a public issue with exploit details.

Include:

- the affected version;
- steps to reproduce;
- expected and observed behavior;
- the security impact;
- a minimal proof of concept when appropriate.

Do not include real user browsing data or other sensitive personal information in reports.
